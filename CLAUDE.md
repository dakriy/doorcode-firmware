Read AGENTS.md before making any change. It is the project contract.
Use the style-develop skill for all coding work in this repository.
Use the style-review skill to audit for complexity, duplication, and test quality.

This repository is public. Commit messages describe the change for a reader of
the project. Never mention the word "slice", the autonomous work loop, handoff
files, subagents, or the operator in a commit message or in code comments.

Committed files never reference the previous implementation, this computer,
or its users. That knowledge lives in `notes/`, which is gitignored and is
where local setup, bench hardware, and in-conversation decisions are recorded.
Public documentation goes in `docs/`.
